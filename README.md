## 패치 내용
* 일본어를 한글로 번경
* 등장인물들의 이름을 고정하고, 이름 변경 기능 삭제

## 패치 방법
* 프로그램을 실행시킵니다.
* 게임이 설치된 폴더를 드래그 & 드롭 합니다.
* [한글 패치] 버튼을 눌러 패치를 진행 합니다.
* 변경된 파일들의 목록이 packed.txt 파일에 기록됩니다.
  * 스팀의 무결성 검사를 하시면 패치전으로 롤백이 가능합니다.

## 요구사항
* Windows 10 이상
* `xextool.exe` 6.3 버전 [다운로드](https://digiex.net/threads/xextool-6-3-download.9523/)
